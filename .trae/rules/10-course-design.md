# 课程设计理念

## 一、核心方法论：用「因果链」替代「知识树」

这是整门课的方法论起点，其他一切标准都从这里推导出来。

**传统知识树**：分类 → 定义 → 公式 → 结论。学生得到的是层级关系（"Self-Attention 是 Transformer 的组件，Q/K/V 是三个矩阵"）。

**病因诊断**：**分类是专家回顾时的视角，不是学习时该走的路径**。学生还没遇到"RNN 处理长句会丢信息"，你直接告诉他"Self-Attention 解决了长距离依赖"——这句话对他只是**一条信息，不是一个领悟**。

**本课程的做法**：问题 → 撞墙 → 尝试 → 再撞墙 → 逼出解法。让 Self-Attention 不是课本上的知识点，而是**学生自己发现"需要它"之后才出现的答案**。

| | 传统教法 | 本课程教法 |
|---|---|---|
| 开场 | "今天我们来学 Self-Attention，它是 RNN 的优化" | "RNN 传 50 步后还剩 0.005，怎么解决？" |
| 路径 | 分类 → 定义 → 公式 → 结论 | 问题 → 撞墙 → 尝试 → 再撞墙 → 逼出解法 |
| 学生得到 | 记住层级关系 | 理解"为什么会需要它" |

### 五阶段认知链（每张卡片的骨架）

```
激活 → 锚定 → 推导 → 升华 → 追问
```

| 阶段 | 目的 | 载体 |
|---|---|---|
| 1 **激活** | 场景化问题让学生**先自己想 30 秒**；提示降低门槛但不给答案 | `.card-q-text` + `.card-q-hint` |
| 2 **锚定** | 标注论文来源和年代，建立学术锚点，不假设前置知识 | `.card-bg` 知识背景 |
| 3 **推导** | **用具体数字把机制"跑"一遍**，概念从算式中长出来；每步独立标题 | `.calc-block` |
| 4 **升华** | 展示冲突：有 X → 结果 A，没有 X → 结果 B，**让学生看到代价** | `.highlight-box` |
| 5 **追问** | 学生下一步最想问的问题已备好答案；AI 接住剩余疑问 | `.qna-list` + `#tab-ai-N` |

## 二、三条设计标准（从因果链自然导出）

> 不是拍脑袋定的原则，而是"当你用因果链替代知识树之后，这三条会**反复出现**"——是被发现的，不是被发明的。

| # | 标准 | 解决的问题 | 传统做法 | 本课程做法 |
|---|------|-----------|---------|-----------|
| 1 | **问题驱动** | 学生不知道为什么要学这个 | "今天我们来学 Self-Attention" | "RNN 传 50 步后梯度只剩 0.005，怎么让每个词同时看到所有词？" |
| 2 | **计算走查** | 懂了概念但算不来 | 给公式 + "它将词间关系编码为注意力权重" | 句子"我吃"、2 词 3 维：Q×K^T → 0.38 → ÷1.41 → [0.54, 0.46] → 加权 V → [0.71, 0.25] |
| 3 | **冲突可见** | 记住解法但不知道代价 | "除以 √d_k 可以稳定训练" | 不除的后果：点积飙到几个数量级 → Softmax 逼近 one-hot → 梯度消失 |

另有一条支撑标准：**知识背景锚定真实历史**——`.card-bg` 给出提出者 + 年份 + 当时要解决的痛点，让学生知道这个设计不是凭空来的。

### 与国际教学法的一一对应（设计依据）

| 业界先进方法 | 本课程对应实现 |
|---|---|
| Prior Knowledge Activation | 问题驱动：每卡以问题开头，先想 30 秒 |
| Chain-of-Thought Pedagogy | 因果链代替知识树：理解来自重建推理路径，而非呈现结论 |
| **First Principles Thinking** | **计算走查**：从最基础真理出发、自下而上建构；"重来一遍自己也能推导" |
| Trivium Arc（Grammar→Logic→Rhetoric） | 五阶段认知链：激活 → 锚定 → 推导 → 升华 → 追问 |
| Spiral Pedagogy | 拒绝线性推进，每课 6 卡形成认知闭环，逐课递进 |
| Avoiding Methodological Pitfalls | 冲突可见：不除 √d_k 会怎样 |
| Organization & Structure | calc-block 每步独立标题、数字自然导出、无魔法常数 |

**深入简出**是上述方法的外显结果：入口 = 1 个问题 + 1 个最小例子；底盘 = 结论能一路推到工程细节。

### 深入简出的判定标准（可核查，来自第 1 课实测）

| 维度 | 判定 | 第 1 课实测 |
|---|---|---|
| **入口够简** | 一张卡 ≤1 个问题 + ≤1 个最小例子；开场不出现未解释的 `d=128 / 频率=10000` 这类常数 | Card 2 达标（"我吃"、2 词 3 维） |
| **底盘够深** | 卡末能自然接出下一层的追问，且追问有数字答案 | 达标（追问均带 table） |
| **够生动** | 每个新机制/术语在**正文**里有 ≤2 句的生活类比；优先用学员**每天都在用**的东西 | ⚠️ **欠账**：最好的类比（图书馆索书号、输入法联想、完形填空）全被埋在追问里 |

> 结论：**计算走查优秀 ≠ 讲解生动**。第 1 课 6 张卡数字几乎全对（唯一例外是 Card 3 的 Softmax 算错），但抽象机制在正文里几乎没有可复用的生活类比。新增卡片必须补上这一课，具体 5 条硬规则见 `20-content-rules.md` 第七节。

## 三、内容质量基准：Lesson 1 Card 2（Self-Attention 计算走查）

> 每张卡片的 `.calc-block` 必须通过以下四条硬核检查，不合格就重写。

| # | 标准 | 正例（L1-C2） | 反例 |
|---|------|-------------|------|
| 1 | **最小真实句子驱动** | 句子 = "我吃"，2 个词、3 维 | "设 d=128、频率=10000" 开场 |
| 2 | **数据用 HTML table 承载** | Embedding / QKV / 注意力矩阵全是 `<table>` | 数字嵌在文字行里 |
| 3 | **每步独立标题** | "Step 1：输入 Embedding" → "Step 2：乘 W^Q…" | 连续 step-desc 无分段标题 |
| 4 | **无魔法常数** | √d_k = √2 ≈ 1.41（因 d_k = 2，自然导出） | 10000、128 来源不可解释 |

## 四、卡片解剖（必须一致）

```
.card[data-card="N"]
├── .card-q             问题区（点击展开）
│   ├── .card-num           序号
│   ├── .card-q-content
│   │   ├── .card-q-text    问题（必须问号结尾、不预设结论）
│   │   └── .card-q-hint    提示（方向引导，不含答案）
│   ├── .card-arrow         展开箭头
│   └── .card-check         已学完勾选（localStorage）
└── .card-a             内容区（展开后可见）
    ├── .card-bg            知识背景（提出者 / 年份 / 痛点）
    ├── .content-section    正文段落
    ├── .calc-block         计算走查（step-title + table）
    ├── .highlight-box / .analogy-block / .compare-table   辅助模块
    ├── .tab-bar            「AI 助教 / 预判追问」两个 tab
    │   ├── .tab-btn
    ├── #tab-ai-N          AI 对话（toolbar + messages + input）
    └── #tab-qna-N         预判追问（.qna-header + .qna-list[data-qna="N"]）
```

> 卡片之间**平级**，`.footer-nav` 属于课程级，绝不能出现在 `.card` 内部。

## 五、课程级节奏

- **一课一个主线问题**，课前用 `.roadmap` 预告推理链（节点 + 箭头），`.meta-tags` 标注知识点。
- **卡片间必须桥接**：依赖前卡的概念，下一张卡正文开头用一句话回顾。
- **课与课之间承接**：承接上一课结论，再抛出新问题（例：Card 3 Causal Mask → Card 4 BERT vs GPT 分岔路）。
- **多课节奏统一**：每课的卡片数量、必备模块（roadmap / meta-tags / tab-bar / qna）保持一致。

## 六、面向推荐系统背景的学生

- 只有卡片内容**天然涉及**推荐系统经验时才带一笔（如 BERT Embedding 类比推荐特征），不要为了接地气硬塞。
- 桥接句的合格标准：**学生心里那个问题被答到了**，而不是"提到了推荐场景"。
